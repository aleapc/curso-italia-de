# Estado do SKU DE→Itália

## Não publicar

Este worktree é uma base de produção. A configuração de idioma já aponta para
DE→IT, mas o corpus, o índice de consulta, as imagens, o texto da interface e
o manifesto de áudio ainda são herdados de DE→Espanha. Portanto, qualquer
build nesta fase serve apenas para validar a infraestrutura; não representa o
produto Itália e não pode ser implantado.

## Próximos portões

1. pesquisa factual e cenas italianas por slot;
2. moldes e interferências DE×IT;
3. corpus de 36 partes e consulta;
4. imagens e vozes nativas italianas;
5. geração, ASR, validadores, build, hidratação e publicação.
